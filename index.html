Teacher setup · class multiplayer

Teacher setup · class multiplayer, no student sign-in

Do this once (about 10 minutes). Firebase is Google's free service; it passes players' positions and scores between computers. Students never sign in to anything.

  1. Create a free Firebase project. Go to console.firebase.google.com, sign in with your Google account, click Create a project (or Add project), name it ib-byte-escape, turn Google Analytics off, and click Create project.
  2. Create the database. In the left menu open Build → Realtime Database, click Create Database, pick United States, choose Start in locked mode, and click Enable.
  3. Paste the security rules. Open the Rules tab, delete everything there, paste these rules, and click Publish.

  4. Copy your settings. Click the gear icon → Project settings. Under Your apps click the web icon </>, type any nickname, click Register app, and copy the whole block that starts with const firebaseConfig = {. It must include a databaseURL line.
